# Проект "Виджет финансовых операций клиента". 
Урок 10.1

## Описание.
Данный проект предусматривает отображение нескольких последнихуспешных банковских операций клиента в личном кабинете и выводит данные для отображения в виджете.

## Установка
+ Клонируйте репозиторий: 
```
https://github.com/Sky-watcher43/homework_10_1_new.git
```
+ Установите зависимости:
```
poetry install
```
## Использование:
Запустите модуль src/processing.py, в качестве аргументов функций подставляя данные, состоящие из даты и статуса операции. 

## Тестирование:
Проект использует `pytest` для написания и выполнения тестов. Для установки pytest через Poetry выполните команду poetry add --group dev pytest/
Для запуска всех тестов выполните в корневой директории проекта команду pytest tests/ или укажите конкретный файл, например pytest tests/masks.py
Это позволит убедиться, что все функции проходят проверку и проект работает корректно.
